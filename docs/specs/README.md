# 规格（Spec）总览

本目录保存 topic-level specification：每个 spec 对应一个稳定的能力、接口或约束，
而不是单次任务的进度卡片。

每个主题包含：

- `SPEC.md`：当前有效的规范和验收条件。
- `IMPLEMENTATION.md`：实现覆盖、状态和未完成项。
- `HISTORY.md`：影响长期理解的决策理由。
