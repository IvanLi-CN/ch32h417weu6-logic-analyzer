# 参考工程中 `VDDIO` 串联磁珠的设计理由核验

## 结论

**没有找到参考工程作者直接说明该串联磁珠的目的。**特别是，未找到作者写明它用于：

- 隔离 `VDDIO` 的高频回流；
- 保护 `VREFP` 或 `VDD33A` 的噪声；
- 建立 `VDD33A >= VDDIO`；或
- 满足 HSADC 的 `VDDIO >= VREFP`。

因此，不能把“参考工程放了一颗磁珠”当作本项目也必须保留该隔离边界的证据。

## 已检索的一手材料

### 原始 OSHWUB 项目作者 `Q2H2`

原始项目页面将 CH2003K 的内部 LDO 输出描述为 CH32H417 的 `3.3 V` 电源，另一路
DCDC 是可调的 `VIO18` 供电。页面也说明 HSADC 用于模拟采样，但没有在项目说明中提到
`VDDIO`、`VREFP`、`VDD33A` 之间的磁珠，也没有说明其作用。[P1]

在 2026-08-25 的公开页面中，项目计数显示 492 条评论；可见的项目说明和已加载评论文本中
均未找到这颗磁珠的用途说明。该结果只能说明没有找到公开作者说明，不能证明作者从未在其他
私有渠道说明过。

### 用户提供的本地参考工程

`ProPrj_CH32H417 USB3.0逻辑分析仪_2026-08-20.epro2` 的 `project2.json` 自称“基于
开源 CH32H417 逻辑分析仪项目改进而来”，故它是派生工程，且文件不含可验证的作者身份。
它的工程说明有两条相关原话：

> “FB 分压网络经过特殊设计以符合主控芯片数据手册电压关系要求。”

> “新增极低纹波线性稳压器用于模拟信号采样。”

同一说明还写明通过调整逻辑电平，将总电源关系维持为
`VDD33 >= VDD33A >= VDDIO >= VIO18 >= VDDK & VDD12A`。[R1]

这些是设计者明确表达的目标，但有严格边界：`FB 分压网络`指的是三路降压器的反馈分压，
文本没有把该说法归因于 `VDDIO` 串联磁珠；“极低纹波 LDO”也只明确服务于模拟采样，未说明
向 `VDDIO` 的串联供电支路。不能将两句话扩展为“作者已经解释磁珠用于噪声隔离”。

### 原理图事实

本地派生参考工程的网络连接为：低纹波 LDO 输出 `AVCC`，`AVCC` 送至 `VDD33A`；外部
`VREFP` 接到该模拟/参考网络；一颗 TDK 电源线磁珠再把这个网络送到 `VDDIO`。这证明了
拓扑，**不证明作者意图**。[R1]

## 可以作出的、但必须标为推论的解释

WCH 对该系列给出一般电压层级 `VDD33 >= VDD33A >= VDDIO >= VIO18`，且 QEU6 在 HSADC
工作条件下还要求 `VDDIO >= VREFP`。TDK 将参考磁珠归类为电源线用器件，规格为
`220 Ohm @ 100 MHz`、`Rdc <= 50 mOhm`。这些资料说明：该拓扑**可能**追求电源层级和改变
高频电流路径；它们不说明参考工程设计者实际选择它的理由。[W1][W2][T1]

更重要的是，串联元件在有正向 `VDDIO` 电流时存在非零压降。所以“用该磁珠来隔离”与
“HSADC 期间保证 `VDDIO >= VREFP`”不是同一个命题，后者不能由此拓扑本身证明。

## 对本项目可转移与不可转移的内容

| 结论 | 是否可转移到 WEU6 | 原因 |
| --- | --- | --- |
| 需要满足 WCH 的电源关系和引脚去耦 | 是 | 这是芯片原厂约束。 |
| 模拟采样电源应按噪声和瞬态指标设计 | 是 | 这是项目的 20 MS/s HSADC 目标带来的工程需求。 |
| `VDD33A` 与 `VDDIO` 之间应保留串联磁珠 | 否 | 没有作者说明；而 WEU6 的 `VREFP` 未引出并在封装内等于 `VDD33A`，与 QEU6 的外部 `VREFP` 拓扑不同。 |
| 磁珠一定能降低 ADC 噪声 | 否 | 缺少本板的负载频谱、PDN 阻抗、布局与实测结果。 |

故后续应先为本项目独立定义：需要抑制的噪声源、允许的 `VDD33A`/`VDDIO` 差分电压、各域本地
去耦和电流回路；再由这些量决定是否需要磁珠以及它应位于何处。参考工程只能提供一个待验证的
实现例，不能代替这些设计输入。
