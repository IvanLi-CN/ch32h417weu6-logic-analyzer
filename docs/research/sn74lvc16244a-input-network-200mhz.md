# SN74LVC16244A 输入网络与 200 MS/s 评估

## 范围与当前网络

本文记录当前保存的工程源文件中探头至 `SN74LVC16244ADGGR` 的输入网络，
以及该网络相对于 16 通道、200 MS/s 捕获目标的可证明边界。它不以参考项目
的元件值替代器件数据表、PCB 寄生参数或样机测量。

当前工程的 U1 所有供电脚连接 `1V8`，所有 `OE#` 脚接地。每个数字输入的拓扑为：

```text
H1 CHx -> TPD4E05U06 -> 47 ohm -> U1 Ax
                                  |
                                330 kohm
                                  |
                                 GND
```

- `D5` 至 `D8` 是四路 `TPD4E05U06` ESD 阵列。
- `RN3`、`RN4`、`RN9`、`RN10` 提供每路 `47 ohm` 串联电阻。
- `RN1`、`RN2`、`RN7`、`RN8` 提供每路 `330 kohm` 下拉电阻。

产品需求中描述的可选 `VIO18` 捕获域是系统目标；本文仅将当前保存网络的
`1V8` 连接作为已核验事实，不以目标电压代替现状。

## 器件边界

在 `VCC = 1.8 V` 时，SN74LVC16244A 保证：

| 项目 | 数值 | 含义 |
| --- | ---: | --- |
| 推荐 `VI` | `0 V` 至 `5.5 V` | 正常 5-V 逻辑输入属于推荐工作范围。 |
| `VIH(min)` | `0.65 × VCC = 1.17 V` | 高电平保证阈值。 |
| `VIL(max)` | `0.35 × VCC = 0.63 V` | 低电平保证阈值。 |
| `II` | `+/-5 uA` 最大 | 测试条件为 `VCC = 3.6 V`、`VI = 0` 至 `5.5 V`；它是保证边界，不是本板的典型漏电预测。 |
| `Ci` | `5.5 pF` 典型 | 测试条件为 `VCC = 3.3 V`、`TA = 25 C`；没有最大值，不能用作 RC 最坏上界。 |

`TPD4E05U06` 的连续工作电压为 `5.5 V`，线路电容为 `0.5 pF` 典型。它位于
47-ohm 电阻的连接器侧，因此其电容是信号源负载，不直接并入 U1 `Ax` 节点的
后串阻 RC 电容。

SN74LVC16244A 未给出最小输入脉宽、最高保证输入频率或 200-MHz 运行保证。
其时延测试中出现的 `PRR <= 10 MHz` 是测试条件，不是器件最大工作频率。

## 330 kohm 下拉的定位

`330 kohm` 在正常被驱动时是高阻下拉：5-V 输入的静态电流为
`5 V / 330 kohm = 15.15 uA`，电阻功耗为 `75.8 uW`。即使按缓冲器公布的
`5 uA` 输入漏电边界合并计算，47-ohm 电阻上的 DC 压降也只有约 `0.95 mV`。

它应被定义为**弱偏置**，而不是数据表级的故障安全低电平保证。对 330-kohm
标称值，若漏电流方向把电流注入 `Ax`，保证 `Ax <= VIL` 的总漏电预算为：

```text
0.63 V / 330 kohm = 1.91 uA
```

TI 的 `+/-5 uA` 规格大于该预算，但其测试条件是 `VCC = 3.6 V`，且它不预测
当前板、温度和器件批次的实际漏电。因此，这一比较说明 330-kohm 不能仅凭
数据表取得全 PVT 的悬空低电平保证；它不证明当前或参考设计必然失效。

当前决定是保留 `330 kohm`，以维持参考设计对探头侧高阻输入的取舍。只有当产品
要求明确为“所有未接探头通道在全工作条件下都必须保证读低”，并且实测不能证明
总注入漏电小于上述预算时，才应改用更强的下拉或可选并联下拉。`82 kohm` 或
`100 kohm` 只改善这个悬空偏置边界，不改善 200-MHz 边沿或采样率。

330-kohm 在源切换为高阻后的放电也较慢。以 `Ci = 5.5 pF` 的典型模型，节点从
5 V 衰减到 `0.63 V` 约需 `3.76 us`；这是断开或高阻源释放的行为，不是正常
低阻逻辑驱动的下降沿时间。

## 47 ohm 串阻的动态边界

U1 节点的一阶近似为：

```text
Rth = 47 ohm + Rs
tau = Rth × CA
t10-90 ~= 2.2 × tau
```

其中 `Rs` 是外部源阻抗，`CA` 是 U1 输入电容与 47-ohm 后走线、过孔、焊盘的
总电容。当前 PCB 的 `Ax` 网络含两个信号过孔，且总铜长约为 7.3 mm 至 10.3 mm；
工程没有可用于签核的该节点寄生电容或阻抗提取值。

下表只用于参数敏感性，不是实际板的最坏情况保证。`Rs = 50 ohm` 指的是外部
信号源阻抗，绝不表示 PCB 已确认是 50-ohm 传输线。

| `CA` | `Rs` | `f-3dB` | `t10-90` |
| ---: | ---: | ---: | ---: |
| `5.5 pF` | `0 ohm` | `616 MHz` | `0.569 ns` |
| `5.5 pF` | `50 ohm` | `298 MHz` | `1.174 ns` |
| `7.0 pF` | `0 ohm` | `484 MHz` | `0.724 ns` |
| `7.0 pF` | `50 ohm` | `234 MHz` | `1.494 ns` |

因此 47-ohm 是合理的输入隔离和阻尼起点，但不是 200-MHz 通过保证。减小它会
改善该一阶 RC 的边沿，却会增加振铃、源端峰值电流和保护器件残压下的后级应力；
增大它会进一步减少边沿余量。没有实际 `CA`、源阻抗和波形测量时，不应为追求
200 MHz 而盲目将 47 ohm 改为 33 ohm 或 22 ohm。

## 保护与采样边界

TPD4E05U06 的典型 TLP 钳位值约为 `10 V @ 1 A`，高于 U1 的推荐输入上限。
例如，若后级钳位要将 `Ax` 保持在 5.5 V，47-ohm 电阻将承受约
`(10 - 5.5) / 47 = 96 mA`。这不是 IEC ESD 电流预测，而是说明串联电阻与
TVS 的标称参数不足以证明 U1 的正向过压安全。必须按目标 ESD 标准，在 U1 `Ax`
节点实测残压与电流。

200 MS/s 对应 5 ns 采样间隔。若需求实际是可靠重建 200-MHz 周期信号，其周期
同样为 5 ns，单次等间隔采样会混叠；至少需要 400 MS/s 才能满足其基波的奈奎斯特
条件，方波保真还需要更高带宽。调节下拉或串联电阻不能解决这个采样架构边界。

若项目目标只是 200 MS/s 的逻辑边沿捕获，验收应描述最小可见脉宽、相位关系、
允许漏采概率和 16 通道同时切换条件，而不应把目标笼统写为“200 MHz 信号采样”。

## 验证项

- 在 U1 `Ax` 测量 16 路悬空时的电压，覆盖工作电压、温度和多个器件批次。
- 测量 1.8 V、2.5 V、3.3 V、5 V 逻辑源在 U1 `Ax` 的阈值交越、过冲和振铃。
- 以实际最大边沿速度和 16 通道同时切换验证 `Ax`、U1 `Y`、MCU 输入及电源轨。
- 按目标 ESD 等级测量 TVS 后、47-ohm 后的残压和电流。
- 将采样验收定义为可重复的最小脉宽与相位扫描，而不是只用缓冲器传播延迟判定。
