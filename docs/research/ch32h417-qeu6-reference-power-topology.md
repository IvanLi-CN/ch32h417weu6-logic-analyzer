# CH32H417QEU6 参考工程的模拟与 I/O 供电拓扑

## 范围与证据等级

本文只分析用户提供的参考工程和器件原厂资料，不把结论外推到其他设计。

- **参考工程事实**：从 `ProPrj_CH32H417 USB3.0逻辑分析仪_2026-08-20.epro2` 的原理图对象、网络和器件属性直接读取。
- **官方约束**：WCH `CH32H417DS0-EN` 与 TDK `MPZ1608S221ATA00` 原厂资料中的明确规格。
- **工程推论**：由上述事实和约束推导出的设计意图或风险；它不是原厂对该参考拓扑的认证。

## 结论

**参考工程中的 U8 并不是为 `VDDIO` 单独配置的必需 LDO。**它把 `TPS7A2033PDBVR` 的输出命名为 `AVCC`，用作 `VDD33A` 和接至 `VREFP` 的 `VREF` 网络的低噪声源；`VDDIO` 再从该源的下游经 L4 磁珠取得供电。这是参考工程的供电策略，不是 CH32H417 对 `VDDIO` 的硬性外置 LDO 要求。[R1][W1]

该策略有可理解的噪声隔离和电压层级意图，但在启用 HSADC 时，`VREFP -> L4 -> VDDIO` 的串联位置不能仅靠原理图形成 `VDDIO >= VREFP` 的硬保证。应通过引脚处的瞬态测量确认。

## 参考工程事实

### 器件与实际连线

| 项目 | 参考工程事实 |
| --- | --- |
| MCU | U5 标注为 `CH32H417QEU6`。该封装有外部 `VREFP` 引脚。 |
| 模拟 LDO | U8 标注为 `TPS7A2033PDBVR`，其输出网络名为 `AVCC`。 |
| 模拟/参考支路 | `AVCC` 连接至 U5 的 `VDD33A`；`VDD33A` 通过短接符号与接至 U5 `VREFP` 的 `VREF` 网络相连。 |
| I/O 支路 | L4 标注为 `MPZ1608S221ATA00`，位于 `VREF`（即 U5 `VREFP`）网络和 `VDDIO` 网络之间。 |
| 独立命名的 3.3 V 轨 | 工程另有由 EA3036 生成的 `3V3` 网络；U5 的 `VDDIO` 在原理图中并未直接接到该网络，而是来自 L4 的下游。 |

以上均为参考工程事实。[R1] 因此，相关供电路径可准确概括为：

```text
U8 TPS7A2033PDBVR
          |
        AVCC
          |
       VDD33A ---- short ---- VREF (to U5 VREFP)
                                  |
                     L4 MPZ1608S221ATA00
                                  |
                                VDDIO
```

参考工程的文字说明将这颗低纹波 LDO 描述为“用于模拟信号采样”，并称其电源分压网络用于满足主控的电压关系。这说明了设计者的目标，但不是 WCH 对该具体连接方式的批准。[R1]

## 官方约束

### WCH 对各电源的定义

**官方约束。**WCH 在数据手册第 1.4.3 节（印刷页 7）规定：[W1]

- `VDD33A` 为 ADC、HSADC、OPA、CMP、DAC、PLL 等模拟部分供电；使用 OPA 或 DAC 时，建议 `VDD33A` 与 `VDDIO` 使用相同电压。
- `VDDIO` 为部分常规 I/O 供电，并给芯片内部 I/O LDO 供电以产生 `VIO18`。这段描述没有要求 `VDDIO` 使用独立的外置 LDO。
- `VDDIO` 不得高于 `VDD33`，也不得高于 `VDD33A`；正常情况下 `VIO18` 由该内部 I/O LDO 产生。
- 电压关系为 `VDD33 >= VDD33A >= VDDIO >= VIO18`，并且 `VDD33A >= VREFP`。
- 主 `VDDIO`（与 `VIO18` 相邻）建议就近配置 `0.1 uF` 加至少 `10 uF` 的去耦电容。

WCH 的 QEU6 引脚资料还列出了外部 `VREFP`、`VDD33A` 和多个 `VDDIO` 引脚；这正是参考工程能把这些网络分别布线的前提。[W1]

### HSADC 的额外下限

**官方约束。**WCH 数据手册表 3-52（印刷页 117）在 HSADC 条件下给出：[W2]

```text
VREFP <= VDD33A
VDDIO >= VREFP
```

其中 `VDDIO >= VREFP` 是 HSADC 条件下的下限，不应被一般的 `VDD33A >= VREFP` 关系替代。WCH 同页还要求 `VREFP` 外接电容尽可能靠近引脚。[W2]

### L4 不是零阻抗连接

**官方约束。**TDK 将 `MPZ1608S221ATA00` 归类为电源线用磁珠，给出的指标包括：[T1]

- 100 MHz 阻抗：`220 Ohm +/-25%`
- 最大直流电阻：`50 mOhm`
- 额定电流：`2.2 A`

这些参数说明 L4 可用于衰减高频电流噪声，但它不是零欧姆短接，也不是稳压器。

## 为什么参考工程不直接使用独立 `3V3`

### 可以由证据支持的意图

**工程推论。**将 `VDDIO` 放在 `VDD33A/VREFP` 的下游，至少有两个可理解的目标：

1. 让 `VDDIO` 的额定电压不会高于模拟/参考支路，从而在标称状态下顺着 `VDD33A >= VDDIO` 的方向建立电压关系。
2. 让 I/O 负载的高频电流通过 L4 与其本地去耦回路闭合，降低其回灌到 `VREFP`/`VDD33A` 支路的机会。

若把 `VDDIO` 直接接至独立调节的 `3V3`，即使两个网络都标称为 3.3 V，稳态公差、上电次序、负载瞬态与布局阻抗仍可能使 `VDDIO` 高于 `VDD33A`。参考工程说明没有明说设计者为何放弃直连 `3V3`，因此上述两点只能作为工程推论，而不能当作已证实的设计说明。[R1][W1]

### 这不等于 `VDDIO` 必须使用 LDO

**工程推论。**U8 的位置和网络命名表明，低噪声 LDO 首先服务于 `VDD33A/VREFP`。`VDDIO` 借用了这个低噪声源的下游支路，以同时服从其与模拟电源、参考电压及 `VIO18` 的关系。WCH 的官方要求是电压范围、层级和去耦，不是为 `VDDIO` 单独增加一颗外置 LDO。[R1][W1]

## 串联磁珠的边界

**工程推论。**在正常供电方向上，电流从 `VREF`/`VREFP` 侧经 L4 流向 `VDDIO` 侧时，L4 的直流电阻和频率相关阻抗都会使两侧电压不再严格相等。以 TDK 给出的最大 `50 mOhm` 和 WCH 表 3-52 的 `1.8 mA` HSADC I/O 引脚电流典型值计算，仅该静态电流的最大压降约为 `90 uV`；数值很小，但并不为零。[T1][W2]

更重要的是，`220 Ohm @ 100 MHz` 是器件测试条件下的阻抗指标，不能直接代入为电源瞬态压降；实际差分电压取决于 L4、两侧去耦、电源输出阻抗、PCB 回流路径和 I/O 负载频谱。它足以证明该路径不是理想短接，却不足以证明任何瞬态下都满足 `VDDIO >= VREFP`。[T1][W2]

因此：

- 对 OPA/DAC 而言，WCH 的“同电压”是建议；L4 使两轨的动态等效不再严格相同，应以测量评估。
- 对 HSADC 而言，`VDDIO >= VREFP` 是表 3-52 的供电下限。由于 `VDDIO` 位于 L4 下游，参考工程不能仅凭拓扑获得这一条件的硬保证。

## 可执行的测量验证清单

以下验证针对参考工程本身。测量点应尽量取在 U5 引脚或对应的最近去耦电容焊盘，而不是远端电源输出端。

1. 使用至少三通道示波器或差分探头，同时观察 QEU6 的 `VDD33A`、`VREFP` 和主 `VDDIO`；若设备允许，同时记录 `VIO18`。QEU6 的主 `VDDIO` 位于 `VIO18` 相邻位置，适合作为主测量点。
2. 对每一条单端电压使用短接地弹簧或差分探头，记录探头带宽、接地点和测量点；长地线会把探头回路噪声误判为磁珠两端压差。
3. 在以下状态分别采样并保存波形：上电和复位、空闲运行、HSADC 连续最高采样率、I/O 高翻转负载、`VIO18` 的各个预期配置及配置切换瞬间。
4. 直接测量 `VREFP - VDDIO` 的差分波形，分别记录最大、最小和峰峰值。HSADC 工作期间的最大值不得为正，即任何已测到的 `VDDIO < VREFP` 都表示未满足表 3-52 的条件。
5. 对所有状态检查 `VDD33 >= VDD33A >= VDDIO >= VIO18` 与 `VDD33A >= VREFP`；HSADC 工作时额外检查 `VDDIO >= VREFP`，并确认 `VDD33A` 不低于 WCH 建议的 `3.0 V`。
6. 复核主 `VDDIO` 引脚附近的实际装配去耦是否满足 WCH 建议的 `0.1 uF + 至少 10 uF`；该项应按器件实际有效电容和布局位置判定，而非只看标称值。

只有这些引脚处、覆盖最坏运行状态的结果均满足要求，才可以把该磁珠隔离方案视为已在该参考工程上验证；否则它只能是有工程动机但未被规格充分证明的拓扑。
