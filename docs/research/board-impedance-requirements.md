# 板级阻抗与端接要求

## 结论

原厂资料中，只有 USB 板内信号给出了受控阻抗参考：

| 类别 | 当前网络 | 板级目标 | 是否是“50 ohm 线” |
| --- | --- | --- | --- |
| USB 3.0 SuperSpeed | `TX1P/TX1N`、`TX2P/TX2N`、`RX1P/RX1N`、`RX2P/RX2N`、`SSTXP/SSTXN`、`SSRXP/SSRXN` | 90 ohm 差分是原厂参考目标，不是本板验收条件 | 否。单端值约 45 ohm 只是由叠层和耦合导出的结果，不应机械指定为 50 ohm。 |
| USB 2.0 High-Speed | `HSDP/HSDN` | 90 ohm 差分是原厂参考目标，不是本板验收条件 | 否。同上。 |

其余已审查网络中，没有找到芯片原厂规定的 50 ohm 特性阻抗或外置 50 ohm 端接要求。它们仍有不同的电气约束，尤其是 HSADC 的外部输入阻抗、数字采样链路的边沿反射、晶体回路、I2C 上升时间和 UART 外部线缆边沿，但这些不是 50 ohm 传输线规则。

本结论只覆盖当前网表的电气拓扑；它不能替代 PCB 叠层、线宽/线距、参考平面、过孔和实际长度的物理事实。

## 项目制造边界

本项目选择的板厂工艺无法提供受控差分阻抗和长度匹配。项目已明确决定：不把 90 ohm、P/N 对内等长、场求解、TDR 或眼图作为投板或验收条件，也不要求在 PCB 文件中补齐相应规则。

因此 USB 2.0/USB 3.0 的原厂阻抗资料在本文件中仅作为技术背景，不能被写成当前板的合规结论或待办项。本板按最佳努力原型验收：两种插头方向都能完成 attach、枚举与持续传输即可；不宣称 USB-IF 合规或保证 USB 3.0 5-Gbps 性能。

## 审查范围与方法

- 审查对象：`/Users/ivan/Downloads/Netlist_Schematic1_2026-08-25.enet`。
- 采用 CH32H417、HD3SS3220、OPA2356、SN74LVC16244A 的原厂资料和 USB-IF 资料作为判据。
- “受控阻抗”指在 PCB 上向板厂或 PCB 工具声明并以实际叠层场求解的特性阻抗，不是原理图中某只串联电阻的阻值。

### USB 3.0 SuperSpeed

| 项目 | 结论 |
| --- | --- |
| 当前网络 | Type-C 口侧四对：`TX1P/TX1N`、`TX2P/TX2N`、`RX1P/RX1N`、`RX2P/RX2N`；复用器至 MCU 的两对：`SSTXP/SSTXN`、`SSRXP/SSRXN`。`TX1P/TX1N` 和 `TX2P/TX2N` 还各自经过交流耦合电容形成的内部短网段。 |

| 端接 / 耦合 | MCU 的 USB3.0 电气参数给出 100 ohm 差分发送/接收阻抗，端接由 PHY 定义，不应因为走线受控而另加 45 ohm 或 50 ohm 电阻。HD3SS3220 的 UFP 连接示例在 TX 对上使用 75 nF 至 200 nF 的交流耦合电容，100 nF 为示例值；RX 对由主机偏置。当前网表的 Type-C 发送支路具有四只 100 nF 交流耦合电容，符合这一拓扑，不存在应补的离散 50 ohm 端接。 |
| 参考做法 | 原厂高速差分对建议 P/N 对内长度匹配、等过孔数量与连续参考平面；不要求 TX 与 RX 两对组间等长。避免测试点和分叉 stub；若必须使用过孔，通常按差分对对称处理并控制残桩。交流耦合电容通常选小封装、两线对称放置。上述均不是本板验收门槛。 |
| 网表事实 | 网表能确认六个差分段、Type-C 方向复用和交流耦合位置；不能证明 90 ohm、对内时延差、过孔残桩、ESD 器件走线是否无分叉，或参考平面是否连续。 |

说明：USB-IF 的 Type-C 规范中 90 ohm +/- 5% 是线缆 SuperSpeed 对的要求，不能直接当作 PCB 制造公差。若板厂能力允许，通常先将目标写为 90 ohm differential，再由板厂针对实际叠层给出可制造的线宽/线距和公差；本项目不采用这一制造流程。

## 50 ohm 的正确边界

本板没有 BNC、SMA、RF 同轴接口或要求 50 ohm 源/负载匹配的模拟测量端口。把所有“快信号”统一指定为 50 ohm 会造成错误：

1. USB 的设计对象是差分 90 ohm 链路，而不是每根线强制 50 ohm。单端阻抗会随耦合与叠层变化，必须由场求解同时满足差分目标。
2. HSADC 的核心约束是 `R_AIN` 与采样建立，不是走线特性阻抗；强行加 50 ohm 端接会改变模拟带宽、增益与采样电荷响应。
3. 逻辑采样输入的外部信号源和连接线未知。47 ohm 或 22 ohm 一类串联电阻只能是保护/边沿阻尼元件，不能在没有源阻抗和实际走线信息时宣称为 50 ohm 匹配。
4. I2C 是开漏总线；并联 50 ohm 会让低电平静态电流约为 36 mA (1.8 V/50 ohm)，明显偏离此总线的工作方式。

## 当前项目的验收边界

网表中的 `differentialPair`、`equalLengthNetGroup` 和 `netClass` 均为空；129 条网络规则中的 `TrackPhysics` 也均为空。按本项目制造边界，这是已知且允许的状态，不需要在投板前补成受控阻抗或长度规则。

网表仍不能证明任何物理布线属性，所以不得由它宣称“已满足 50 ohm/90 ohm”。本项目只保留以下不依赖板厂阻抗能力的检查：不为 USB 额外加入 45-ohm 或 50-ohm 离散端接；ESD 器件靠近连接器并具有低电感接地回路；模拟、逻辑、晶体和 I2C 继续按各自的电气约束处理。USB 数据路径是否可用由成板上的双方向枚举与持续传输实测决定。
