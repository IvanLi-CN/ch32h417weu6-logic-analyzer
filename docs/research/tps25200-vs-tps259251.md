# TPS25200DRVR and TPS259251DRCR Functional Comparison

## Conclusion

`TPS25200DRVR` is suitable for the new board's protected 5-V input path. It is
a redesign choice, not a pin-compatible conversion from TPS259251DRCR.

For this project, the required function is limited to a 5-V high-side switch
with programmable current limit, short-circuit and overtemperature protection,
and hot-plug tolerance. Programmable UVLO, a dV/dT pin, and a persistent MCU
fault-observation domain are not requirements.

## Relevant Differences

| Function | TPS25200DRVR | Project consequence |
| --- | --- | --- |
| Continuous output current | Up to 2.6 A recommended | Adequate; the final board budget is not yet frozen. |
| Current-limit programming | One `RILIM` resistor | Common E24 `75 kOhm`, 1%, is a conditional candidate for a <=1.10-A budget and gives approximately 1.175-1.420 A. |
| Fault indication | Active-low open drain | Leave NC. The MCU and pull-up rail are downstream of the protected switch. |
| Output ramp | Internal behavior, no dV/dT pin | Do not recreate a legacy dV/dT capacitor network; measure VDD5 rise at HD3SS3220. |
| Output overvoltage clamp | 5.25-5.55 V specified range | Downstream 5-V loads must be checked against this fault-clamp range. |

## Selected Peripheral Network

```text
USB-C VBUS (VBUS_RAW) -- TPS25200 IN
TPS25200 OUT ---------- VDD5 -- EA3036C input and HD3SS3220.VDD5
TPS25200 EN  <--------- 300 kOhm, 1%, from VBUS_RAW
TPS25200 ILIM <------- RILIM to be frozen after the external-VIO18 maximum-load budget
TPS25200 FAULT ------- NC
```

Fit `0.1 uF`, 50-V X7R plus `10 uF`, 25-V X5R/X7R at IN, and `22 uF`, 16-V
X5R/X7R at OUT. Keep a DNP VBUS-to-GND TVS footprint; do not populate it by
default for a compliant 5-V host.

Full capture is enabled only after HD3SS3220 indicates Medium or High source
current. The eFuse limit protects the board during faults; it does not grant a
Default-current source permission to provide the 1.10-A capture budget.

## Design Boundary

No legacy board, component placement, footprint, pinout, or peripheral network
is used as evidence for this choice. The schematic is captured directly from
the TPS25200 data sheet and [Power Architecture](power-architecture.md).

Sources: [TI TPS25200 data sheet](https://www.ti.com/lit/ds/symlink/tps25200.pdf)
and [TI TPS25200EVM-618 User's Guide](https://www.ti.com/lit/pdf/SLVUA53).
