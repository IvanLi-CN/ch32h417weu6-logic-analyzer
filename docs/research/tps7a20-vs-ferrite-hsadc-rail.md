# TPS7A2033 与磁珠：WEU6 HSADC 供电边界

## 结论

`TPS7A2033PDBVR` 不是“万能净化器”，但它确实提供了磁珠没有的三项能力：受闭环控制的
3.3-V 输出、对输入纹波的可量化典型 PSRR，以及限定带宽内的输出噪声数据。对于本项目从
`+5V` 产生 HSADC 的 `AVCC`，其 `5.0 - 3.3 = 1.7 V` 余量充足；在 100 Hz 至 100 kHz 的
典型 PSRR 很高，到 1 MHz 已明显下降。其数据不能外推为 10 MHz 以上的保证，亦不能替代布局和
去耦。

`CBM201209U102T` 的 `1000 Ohm @ 100 MHz` 只是在 `50 mV` 小信号测试下的阻抗规格，不是
“100 MHz 纹波一定衰减多少 dB”的规格；其 `0.12 Ohm` 只限制直流压降。磁珠可以用于隔离高频
电流回路，但不能稳压、不能抑制直流/低频纹波，也不能单独证明 HSADC 电源满足噪声或瞬态目标。

因此，若首板目标包含可重复的 HSADC 模拟性能，应保留 U8；若为了 BOM 删除 U8，则只能把磁珠
方案作为待实测验证的替代方案，不能声称与 LDO 等效。

## TPS7A2033 的实际能力与边界

本项目使用的 `TPS7A2033PDBVR` 是固定 3.3-V、SOT-23 (`DBV`) 版本。TI 的以下 PSRR 与噪声
数值均为典型值，不是最小保证值。

| 项目 | TI 数据 | 对本项目的意义 |
| --- | --- | --- |
| 工作范围 | `VIN = 1.6-6.0 V`，`IOUT = 0-300 mA` | `+5V -> 3.3V` 在工作范围内。 |
| 调节余量 | TI 建议 `VIN >= VOUT(NOM) + 0.3 V` | 实际余量 `1.7 V`，不是 dropout 工况。 |
| 输出精度 | `+/-1.5%` 最大值，适用于 `DBV` 的 `VOUT >= 2.8 V`、`VIN` 至 6 V、`1-300 mA` | 绝对输出仍可能为 `3.2505-3.3495 V`；它不是高精度基准源。 |
| Dropout | `145 mV` 最大值，`VOUT = 3.3 V`、`300 mA`、`DBV` | 仅说明接近输入电压时的调节余量；不是 PSRR 指标。 |
| 输出噪声 | `7 uV RMS`（`300 mA`）或 `10 uV RMS`（`1 mA`），带宽 `10 Hz-100 kHz`、`VOUT = 2.8 V` | 很低，但不能直接当作本项目 3.3-V、10-MHz 采样带宽内的保证噪声。 |
| 输出电容 | 有效值 `0.47-200 uF`、ESR 不大于 `100 mOhm`；标称建议 `1 uF` | `C56` 的标称值不是充分条件，须核对其在 3.3 V、温度和偏压下的有效电容，并贴近 U8 的 OUT/GND。 |

来源：TI [TPS7A20 Rev. H 数据手册](https://www.ti.com/lit/ds/symlink/tps7a20.pdf)，第 5-7、27、31 页。

### PSRR 的量级

TI 在 `VIN = VOUT + 1.0 V` 的条件下给出下表；所有数值为典型值。它们说明 LDO 对低至中频输入
纹波的抑制很强，但不是全频段恒定的指标。

| `IOUT` | 100 Hz | 1 kHz | 10 kHz | 100 kHz | 1 MHz |
| --- | ---: | ---: | ---: | ---: | ---: |
| 20 mA | 95 dB | 95 dB | 75 dB | 75 dB | 45 dB |
| 300 mA | 65 dB | 92 dB | 75 dB | 60 dB | 40 dB |

以同一频率、`100 mV` 正弦输入纹波作纯粹的量级示例，使用
`VOUT,ripple = VIN,ripple / 10^(PSRR/20)`：

| `IOUT` | 100 kHz 输出纹波 | 1 MHz 输出纹波 |
| --- | ---: | ---: |
| 20 mA | 约 `17.8 uV` | 约 `0.562 mV` |
| 300 mA | 约 `0.100 mV` | 约 `1.00 mV` |

在 `3.32 V`、10 位 HSADC 下，1 LSB 约为 `3.24 mV`；上述 1-MHz 示例已约为
`0.17-0.31 LSB`。这不是本板的预测值，因为当前没有 `3V3` 的纹波频谱、实际 U8 负载、输出电容
有效值或 PCB 寄生参数；它只说明不能把“95 dB @ 1 kHz”错误外推到所有频率。

TI 的图 5-61 至图 5-64 还表明，PSRR 会随输入电压、负载和输出电容改变。图表延伸到 10 MHz，
但仅是 `VOUT = 2.8 V` 等特定条件下的典型曲线；TI 的表格 PSRR 数据只列到 1 MHz。实际
`+5V -> 3.3V` 的 1.7-V 余量优于表格的 1.0-V 测试余量，但不能据此声明更高或保证的 PSRR。

来源：TI [TPS7A20 Rev. H 数据手册](https://www.ti.com/lit/ds/symlink/tps7a20.pdf)，第 7、18 页。

### 电容、输入阻抗与热边界

LDO 的 PSRR 不意味着输入侧可以任意差。TI 要求输入电源本身受调节且无杂散噪声；当输入源阻抗
大于 `0.5 Ohm`，或存在快速负载瞬态时，需在 U8 的 IN/GND 就近配置足够输入电容，否则可能出现
振铃或系统级不稳定。若在 U8 输入前加入磁珠，U8 输入侧的这颗电容仍是必需的。

损耗由 `PD = (VIN - VOUT) x IOUT` 决定。对 `5.0V -> 3.3V`：

| `IOUT` | U8 估算损耗 | 用 DBV `RthetaJA = 187.1 C/W` 得到的 JEDEC 板一阶温升 |
| --- | ---: | ---: |
| 10 mA | 17 mW | 约 3.2 C |
| 50 mA | 85 mW | 约 15.9 C |
| 100 mA | 170 mW | 约 31.8 C |
| 300 mA | 510 mW | 约 95.4 C |

这些温升仅用于量级判断，实际值取决于铜皮、环境和相邻热源。HSADC 表中的 `1.1 mA` 模拟供电电流
与 `1.8 mA` ADC I/O 电流并不是整个 MCU `VDDIO` 的负载预算；若 U8 还供给一般 I/O，必须按实际
最坏负载重新核算，不能仅以“额定 300 mA”判断安全。

来源：TI [TPS7A20 Rev. H 数据手册](https://www.ti.com/lit/ds/symlink/tps7a20.pdf)，第 5-7、27-31 页；
WCH [CH32H417DS0](https://www.wch-ic.com/downloads/CH32H417DS0_PDF.html)，表 3-52（印刷页 117）。

## CBM201209U102T 的实际能力与边界

风华官方产品页给出的该具体料号规格为：`1000 Ohm +/-25% @ 100 MHz`、测试电压 `50 mV`、
`RDC <= 0.12 Ohm`、额定电流 `1.5 A`。

来源：风华高科 [CBM201209U102T 官方产品页](https://www.fhcomp.com/zh-cn/product_info/?prod_code=CBM201209U102T)。

它能证明的只有：

- 在直流下，最大压降为 `Delta V = I x 0.12 Ohm`。例如 10 mA、50 mA、100 mA 时分别不超过
  `1.2 mV`、`6 mV`、`12 mV`。
- 在 100 MHz、50-mV 小信号测试条件下，器件呈现约 `1 kOhm` 的阻抗量级，因而可与两侧本地去耦
  一起限制高频噪声电流跨支路传播。

它不能单独证明：

- 任意频率（尤其 DC、开关频率、100 kHz 或 1 MHz）的纹波衰减；
- 输出 DC 精度、低频纹波抑制、输出噪声或负载瞬态恢复；
- 100 MHz 处的实际 dB 衰减。该结果还取决于上游输出阻抗、下游各电容的有效 C/ESL/ESR、走线和
  负载频谱；把 `1 kOhm` 当成固定串联电阻来计算是不成立的；
- 在磁珠带有直流偏置、温度变化和真实 PCB 寄生下的阻抗曲线。官方网页给出的单点小信号规格并未
  给出这些工作条件下的完整传递函数。

因此磁珠和 LDO 是互补关系，而非可按阻值直接替换的关系：LDO 对低至中频电源纹波有数据表量级的
闭环抑制；磁珠主要改变高频路径阻抗，必须依赖本地去耦和布局才能体现效果。

## `VDD33A = VREFP = VDDIO` 的连接约束

WEU6 的未引出 `VREFP` 在芯片内等于 `VDD33A`。WCH 同时规定一般供电关系
`VDD33A >= VDDIO`，并在 HSADC 表中规定 `VDDIO >= VREFP`。因此启用 HSADC 时，三者在设计
目标上应为同一条 `3.32-V` 参考/供电轨：

```text
VDD33A = VREFP (internal) = VDDIO = 3.32 V
```

LDO 只能使其 OUT 节点受调节，不能在其下游元件两端自动保持相等。特别是把磁珠串在
`VDD33A/VREFP` 与 `VDDIO` 之间时，`RDC` 和瞬态阻抗都会让 `VDDIO` 相对 `VDD33A` 下降；这不能由
拓扑证明仍满足 `VDDIO >= VREFP`。

正确的拓扑选择是二选一：

```text
# 保留 LDO（模拟性能优先）
+5V -> TPS7A2033 OUT -> common AVCC -> VDD33A
                                         -> VDDIO

# 删除 LDO（BOM 优先，须实测验证）
3V3 -> CBM201209U102T -> common AVCC -> VDD33A
                                             -> VDDIO
```

两种情形中，磁珠若使用，应在 `VDD33A` 和 `VDDIO` 的共同上游；两者之间不要串联磁珠。每个 MCU
电源引脚仍需各自就近去耦，且主 `VDDIO` 处需 WCH 要求的 `0.1 uF` 加至少 `10 uF` 的有效去耦。
为满足 LDO 稳定性，保留 U8 时还要保证其 OUT 处的有效 `COUT >= 0.47 uF`，以及在其 IN 处就近的
输入电容。

来源：WCH [CH32H417DS0](https://www.wch-ic.com/downloads/CH32H417DS0_PDF.html)，第 1.4.3 节
（印刷页 7）与表 3-52（印刷页 117）；本地已核验文本见
[`wch-ch32h417-datasheet.md`](../datasheets/wch-ch32h417-datasheet/wch-ch32h417-datasheet.md)。

## 首板验证门槛

无论是否保留 U8，不能仅根据元件名或标称阻抗确认 HSADC 电源质量。应在 MCU 最近的去耦焊盘处，
以短接地弹簧或差分探头，覆盖上电、连续 20 MS/s HSADC、最大数字 I/O 翻转与所有 `VIO18` 模式，
记录：

1. `VDD33A` 与 `VDDIO` 的直流值、纹波和瞬态差分；WEU6 上以 `VDD33A` 代表内部 `VREFP`。
2. `VDDIO - VDD33A` 的最小值；启用 HSADC 时不得为负。
3. U8 的实际负载、温升和 OUT/IN 处波形；若移除 U8，则记录 `3V3` 与磁珠后共同节点的频谱和瞬态。

只有这些引脚处测量满足供电关系并达到所需采样噪声/线性目标，磁珠方案才可替代 LDO 方案。
