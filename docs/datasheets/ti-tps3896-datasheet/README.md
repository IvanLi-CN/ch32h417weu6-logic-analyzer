# TI TPS3896 Datasheet Source

The local `TPS3896.pdf` copy is TI's TPS389x data sheet, Rev. B. It is kept
with the project as evidence for an alternative `TPS3898ADRYT` hardware-only
power-good circuit for `HD3SS3220.ENn_CC`; that circuit is not populated by
the current netlist.

Primary source: [TI TPS3898ADRYT product page](https://www.ti.com/product/TPS3898/part-details/TPS3898ADRYT)
and [TI TPS389x data sheet](https://www.ti.com/lit/ds/symlink/tps3896.pdf).

The part is active according to TI. Its purchase availability is deliberately
not asserted here; it must be verified with the actual BOM supplier.
